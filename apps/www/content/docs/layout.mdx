## Usage

```tsx
import { ImageEditorLayout } from "@/components/image-editor/layout";

<ImageEditorLayout toolbar={...} sidebar={<ImageEditorCurves />}>
  <ImageEditorCanvas />
</ImageEditorLayout>
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `toolbar` | `ReactNode` | Content of the top bar. |
| `sidebar` | `ReactNode` | Content of the sidebar. |
| `resizableSidebar` | `boolean` | Let users drag to resize the sidebar. Default `true`. |
| `sidebarDefaultSize / sidebarMinSize / sidebarMaxSize` | `string \| number` | Sidebar sizes, e.g. `"338px"`. |
