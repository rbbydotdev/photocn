# Code of Conduct

photocn follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment and personal attacks aren't tolerated in issues, pull requests or any other project space.

To report a problem, message the maintainer privately at [x.com/rbbydotdev](https://x.com/rbbydotdev). Reports are kept confidential.
