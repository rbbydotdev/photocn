`useImageEditorState()` from `photocn/react` returns the same API the components use. Put `canvasRef` (with `key={canvasKey}`) on a `<canvas>` and `stageRef` on its container, and build any UI you like. To share it with child components, pass it to `<ImageEditorProvider editor={editor}>`.

## Lower level

`photocn/hooks` has the building blocks: `useMiniPhotoEditor`, `useEditorHistory`, `useHistogram` and `useExifMetadata`. Outside React, use [`createPhoto()`](/docs/without-react).
