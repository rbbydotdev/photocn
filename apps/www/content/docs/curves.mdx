## Props

| Prop | Type | Description |
| --- | --- | --- |
| `activeChannel` | `"rgb" \| "r" \| "g" \| "b"` | The channel being edited. |
| `size` | `number` | Size of the curve area in px. |
| `histogram` | `RgbHistogram \| null` | Override the histogram behind the curve. |
