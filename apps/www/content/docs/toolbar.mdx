## Usage

```tsx
import {
  ImageEditorToolbar,
  ImageEditorUndoButton,
  ImageEditorRedoButton,
} from "@/components/image-editor/toolbar";

<ImageEditorUndoButton />
<ImageEditorRedoButton />
<ImageEditorToolbar tools={myTools} />
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `ImageEditorToolbar · tools` | `EditorToolbarTool[]` | The tools to show. Default: all of them. |
| `ImageEditorToolbar · actions` | `EditorToolbarAction[]` | Extra icon buttons. |
| `Undo / Redo / Open / Reset / Compare · showLabel` | `boolean` | Show the text label next to the icon. |
