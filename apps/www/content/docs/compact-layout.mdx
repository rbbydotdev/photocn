The full editor switches to this layout on its own when it's narrower than 640px. See [Mobile](/docs/mobile) for how that works and how to opt out.

## Installation

<InstallCommand item="image-editor-compact-layout" />

## Usage

```tsx
// The full editor switches to this layout below 640px wide.
<ImageEditor src="/photo.jpg" layout="compact" />
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `tools` | `EditorToolbarTool[]` | The tools in the bottom bar. |
| `panels` | `Record<toolId, ReactNode>` | Replace or add panels. |
| `panelMode` | `"drawer" \| "inline"` | Where panels open. Default `"drawer"`: a sheet that slides up inside the editor (drag between two heights, or down to close). `"inline"` puts the panel between the photo and the tool bar. |
| `onSave` | `(result) => Promise<void>` | Adds a Save button to the export panel. |
