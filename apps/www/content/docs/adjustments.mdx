## Usage

```tsx
import { ImageEditorAdjustments } from "@/components/image-editor/adjustments-panel";

<ImageEditorAdjustments defaultSection="colors" />
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `defaultSection` | `"lights" \| "colors" \| "effects"` | The tab shown first. |
| `disabled` | `boolean` | Turn off the sliders. |
| `className` | `string` | Classes for the panel. |
