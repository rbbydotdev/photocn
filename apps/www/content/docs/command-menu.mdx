## Props

| Prop | Type | Description |
| --- | --- | --- |
| `shortcut` | `boolean` | Open it with ⌘K / Ctrl+K. Default `true`. |
| `groups` | `EditorCommandGroup[]` | Your own commands, added after the built-in ones. |
| `open / onOpenChange` | `boolean` | Control whether it's open. |
